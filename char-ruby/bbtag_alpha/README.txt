Ruby Rose (Cross Effect), alpha package: the bbtag_alpha folder

The files in "asset" are files of BlazBlue Cross Tag Battle, under the game's own file names: the archives that
Ruby Rose's sprites, animations, effects, voice and sounds are read from. They are in this alpha package so that
testers don't need Cross Tag Battle installed. The install reads them; nothing in this folder is run.

The files in "ui" are nine images of Ruby from that game. The files in "hca" are her sounds and voice lines from those
archives, already converted to the sound format Entropy Effect plays, so that the install needs no converter.

Please don't pass these files on outside this package.
A later release will read them from your own copy of Cross Tag Battle instead.
