# BBEE Redux: public mod files

The mod files of the characters released for BlazBlue Entropy Effect Redux, an unofficial fan project created,
designed and directed by Soulve. Each folder is a mod as its latest public release has it.

Redux is not affiliated with or endorsed by 91Act or Arc System Works.

## What is here

| Folder | Mod | Version |
|---|---|---|
| `char-nine` | Nine the Phantom | 0.9.0 (alpha) |
| `dr-party` | DELTARUNE: Party | 0.6.4 (alpha) |
| `char-ruby` | Ruby Rose | 0.9.0 (alpha) |

Each folder has a `version.txt` with that number. Only public releases come here. Work in progress does not.

## What is not here

- Character sprites, effects and sounds. The files here are the code, tables, scripts, text and icons of each mod.
- Portrait art.

So a folder from here is not a full mod by itself. To play, get **The Zenith Terminal** from the BBEE Discord's
modding channel: it carries the complete characters and installs them. These folders are for the Terminal's updater
and for people who want to read how the mods are made.

## Install

Use The Zenith Terminal. Close the game before installing, and keep the backup of your save that it makes.
The mods are alpha builds: expect bugs, and report them in the Discord thread.
