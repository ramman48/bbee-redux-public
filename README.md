# BBEE Redux: public mod files

The public releases of the BlazBlue Entropy Effect Redux mods, an unofficial fan project created, designed and
directed by Soulve. Each folder is a mod, whole, as its latest public release has it.

Redux is not affiliated with or endorsed by 91Act or Arc System Works.

## What is here

| Folder | Mod | Version |
|---|---|---|
| `char-nine` | Nine the Phantom | 0.9.0 (alpha) |
| `char-ruby` | Ruby Rose | 0.9.0 (alpha) |
| `dr-party` | DELTARUNE: Party | 0.6.4 (alpha) |
| `ex-common` | BlazBlue EX: shared presentation | 0.8.0 (alpha) |
| `ex-ragna` | BlazBlue EX: Ragna EX | 0.8.6 (alpha) |
| `ex-hakumen` | BlazBlue EX: Hakumen EX | 0.5.4 (alpha) |
| `four-player` | Four players online | 0.3.11 (test) |

Each folder has a `version.txt` with its number and a `files.txt` with the sha256 of every file in it. `lists/`
names the folders. Only public releases come here; work in progress does not.

Ruby Rose carries the BlazBlue Cross Tag Battle files she is built from, and DELTARUNE: Party carries the DELTARUNE
sprites, sounds and font it uses. Those files belong to their owners: BlazBlue Cross Tag Battle to Arc System Works,
Ruby Rose and RWBY to RWBY's rights holders, DELTARUNE to Toby Fox and the DELTARUNE team.

## Install

Use **The Zenith Terminal**, from the BBEE Discord's modding channel. It reads this repository every time it opens:
new versions of these mods, and new mods, arrive in it by themselves. Close the game before installing, and keep the
backup of your save that it makes. The mods are alpha builds: expect bugs, and report them in the Discord thread.
